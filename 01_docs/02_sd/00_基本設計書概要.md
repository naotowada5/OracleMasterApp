## 1. 本書の目的・位置付け

本書は `01_docs/01_ra/requirements3.md`（要件定義書 v1.1）を受けて、Phase 1（Web/PWA・Cognito認証必須・サーバーレス構成）のシステムを実装するために必要な基本設計（外部設計）をまとめたものである。

要件定義書で「対応予定（Phase 2/3）」とされている機能（S-04 問題作成・インポート画面、F-08 問題インポート、F-09 AI 問題生成、F-10 進捗管理・履歴保存 等）についても、画面・API・データ項目としての置き場所は本書に記載するが、**Phase 1 では非活性・未実装**として明示する。実装順序を前倒ししないこと。

## 2. 対象範囲（本基本設計のスコープ）

- Phase 1 で開発する画面（S-01〜S-03, S-05〜S-09）の詳細設計
- Phase 3 実装だが Phase 1 で UI 上「非活性」として存在する画面（S-04）の設計（活性化はしない）
- Phase 1 で有効化する API（Cognito 認証必須の REST API）の詳細設計
- Phase 3 実装の API（/questions/import, /questions/generate）は、インターフェース定義のみ本書に記載し、Lambda 実装はスコープ外
- DynamoDB 7 テーブルのエンティティ定義・ER 図・アクセスパターン
- 認証・認可、エラーハンドリング、ログ・監視などのシステム共通設計

## 5. 前提・制約（要件定義書からの再掲）

- 全 API エンドポイントに Cognito オーソライザーを適用する（参照系 API も含む、要件定義書 §7.1 注記）。
- 複数選択問題は選択集合の完全一致でのみ正解とする（部分点なし、要件定義書 F-04）。
- 解説（explanation）は事前登録済みテキストであり、Phase 1/2 では動的生成しない（AI解説は Phase 3, F-11）。
- Phase 1 の初期データ投入は開発者スクリプトによる DynamoDB 直接投入とし、インポート UI（S-04 の JSON インポート部分）は実装しない。
