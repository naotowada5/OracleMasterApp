# テーブル一覧

DynamoDB 上に、要件定義書 §6 に基づき7テーブルを「エンティティ単位のテーブル」として構成する（単一テーブル設計ではない）。

テーブル名は `OR_{テーブル種類}_{テーブル名}` の命名規約に従う（`M`=マスタ / `T`=トランザクション / `W`=ワーク。[命名規約](../04_共通設計/命名規約.md) §2 参照）。実際のデプロイ時は環境プレフィックスを付与する（例: `dev-OR_M_QUESTION`）。

|---|---|---|---|---|---|---|---|
| 1 | OR_M_QUALIFICATION | M | 資格マスタ | qualificationId | - | Phase 1 | [T-01_OR_M_QUALIFICATION.md](個別エンティティ定義書/T-01_OR_M_QUALIFICATION.md) |
| 2 | OR_M_CATEGORY | M | 大問カテゴリマスタ | categoryId | qualificationId | Phase 1 | [T-02_OR_M_CATEGORY.md](個別エンティティ定義書/T-02_OR_M_CATEGORY.md) |

## 共通項目（全テーブル必須）

全7テーブルに、以下の監査用共通項目を設定する。個別エンティティ定義書の属性定義にも各テーブル分を再掲する。

| 論理名 | 属性名 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| 登録日 | createdAt | String | 必須 | レコード作成日時（ISO 8601, UTC） |
| 登録者 | createdBy | String | 必須 | レコードを作成した主体の識別子（下表参照） |
| 更新日 | updatedAt | String | 必須 | レコード最終更新日時（ISO 8601, UTC）。作成時は `createdAt` と同値を設定 |
| 更新者 | updatedBy | String | 必須 | レコードを最後に更新した主体の識別子。作成時は `createdBy` と同値を設定 |

### 登録者・更新者に設定する値

| 書き込み経路 | `createdBy` / `updatedBy` に設定する値 |
|---|---|
| 認証済みAPI（Lambda）からの書き込み | Cognito トークンの `sub`（＝ `userId`）。クライアントが指定した値は使用しない（[認証・認可設計](../04_共通設計/認証・認可設計.md) §3） |
| 開発者スクリプト（`14_script`）による初期データ投入 | 固定値 `SYSTEM` |
| Cognito Post Confirmation Lambda 等のシステム起因の自動作成 | 固定値 `SYSTEM` |

### 実装上の規約

- 共通項目の設定は Lambda の共通レイヤー（[開発タスク一覧](../../03_dev/開発タスク一覧.md) T2-1）にヘルパー関数として実装し、各APIハンドラで個別に組み立てない。
- 更新系の処理では `updatedAt` / `updatedBy` を必ず更新する（`createdAt` / `createdBy` は更新時に上書きしない）。
- 共通項目は監査用の内部項目であり、原則としてAPIレスポンスには含めない（既に返却仕様が定義されている `OR_M_USER.createdAt`（[API-10](../02_API設計/個別API設計書/API-10_ユーザー情報取得.md)）を除く）。

## DynamoDB共通仕様

- キャパシティモード: オンデマンド（要件定義書 §5.2）
- 保存時暗号化: AWS 管理キー（要件定義書 §9.3）
- リージョン: 単一リージョン構成（マルチリージョンはPhase1対象外）
- ID採番: `qualificationId` を除き UUID v4 を基本とする
- 日時属性: ISO 8601 文字列（UTC）
