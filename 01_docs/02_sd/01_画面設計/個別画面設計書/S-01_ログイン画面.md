# S-01 ログイン画面

| 項目 | 内容 |
|---|---|
| 画面ID | S-01 |
| 画面名 | ログイン画面 |
| Phase | Phase 1 |
| 認証要否 | 不要（本画面で認証を行う） |
| 関連機能ID | F-01 |

## 1. 概要

メールアドレス・パスワードにより Amazon Cognito で認証を行い、成功時に S-03 メイン画面へ遷移する。未ログイン状態でアプリの他画面へは遷移できないため、アプリのエントリーポイントとなる。

## 2. 画面イメージ

```
┌─────────────────────────┐
│   Oracle Master 問題アプリ │
├─────────────────────────┤
│  メールアドレス           │
│  [                    ]  │
│                         │
│  パスワード              │
│  [                    ]  │
│                         │
│  ┌─────────────────┐    │
│  │    ログイン      │    │
│  └─────────────────┘    │
│                         │
│  パスワードをお忘れの方   │
│  新規登録はこちら         │
└─────────────────────────┘
```

## 3. 表示項目

| 項目名 | 種別 | 必須 | 説明 |
|---|---|---|---|
| メールアドレス | テキスト入力 | 必須 | Cognito のユーザー名（email）として使用 |
| パスワード | パスワード入力（マスク表示） | 必須 | |
| ログインボタン | ボタン | - | 押下でCognito認証（InitiateAuth）実行 |
| パスワードをお忘れの方 | リンク | - | Cognito のパスワードリセットフロー（画面追加はPhase1範囲外。簡易モーダルで対応） |
| 新規登録はこちら | リンク | - | S-02 へ遷移 |
| エラーメッセージ領域 | テキスト | - | 認証失敗時にインライン表示 |

## 4. 操作・イベント

| No | 操作 | 処理内容 | 遷移先 |
|---|---|---|---|
| 1 | メールアドレス・パスワード入力後「ログイン」押下 | 入力チェック → Cognito にサインイン要求 → 成功時 JWT（ID/アクセス/リフレッシュトークン）をクライアントに保存 | S-03 メイン画面 |
| 2 | 「新規登録はこちら」押下 | - | S-02 新規登録画面 |
| 3 | 「パスワードをお忘れの方」押下 | Cognito ForgotPassword フローのモーダルを表示（メール送信→確認コード→新パスワード設定） | 同画面内モーダル |

## 5. 入力チェック仕様

| 項目 | チェック内容 | エラーメッセージ例 |
|---|---|---|
| メールアドレス | 必須、メール形式 | 「メールアドレスを入力してください」「メールアドレスの形式が正しくありません」 |
| パスワード | 必須 | 「パスワードを入力してください」 |

## 6. 使用する外部インターフェース

- Amazon Cognito User Pool（`InitiateAuth` / `ForgotPassword` / `ConfirmForgotPassword`）。バックエンド API は使用しない（Cognito SDK をクライアントから直接呼び出す）。

## 7. エラーハンドリング

| ケース | 表示内容 |
|---|---|
| メールアドレス/パスワード誤り | 「メールアドレスまたはパスワードが正しくありません」 |
| 未確認アカウント（メール認証未完了） | 「メールアドレスの確認が完了していません。確認メールをご確認ください」 |
| ネットワークエラー | 「通信エラーが発生しました。時間をおいて再度お試しください」 |
| アカウントロック（試行回数超過） | Cognito のロックポリシーに従いエラーメッセージを表示 |

## 8. 備考

- ログイン成功後、直前に保存していた遷移先（ディープリンク等）があればそちらへ復帰する。指定がなければ S-03 へ遷移する。
- PWA のホーム画面追加後もこの画面が起動時の入口となる（認証トークン有効時はスキップし S-03 へ自動遷移）。
