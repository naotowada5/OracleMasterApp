# S-03 メイン画面

| 項目 | 内容 |
|---|---|
| 画面ID | S-03 |
| 画面名 | メイン画面 |
| Phase | Phase 1 |
| 認証要否 | 必要 |
| 関連機能ID | F-02 |

## 1. 概要

ログイン後に表示されるホーム画面。「問題作成・インポート」「問題スタート」「問題閲覧」の3機能へのナビゲーションを提供する。

## 2. 画面イメージ

```
┌─────────────────────────┐
│  こんにちは、〇〇さん      │
├─────────────────────────┤
│                         │
│  ┌─────────────────┐    │
│  │  問題スタート     │    │
│  └─────────────────┘    │
│                         │
│  ┌─────────────────┐    │
│  │  問題閲覧        │    │
│  └─────────────────┘    │
│                         │
│  ┌─────────────────┐    │
│  │ 問題作成・インポート│(非活性)│
│  └─────────────────┘    │
│                         │
│                  [ログアウト]│
└─────────────────────────┘
```

## 3. 表示項目

| 項目名 | 種別 | 必須 | 説明 |
|---|---|---|---|
| ログインユーザー名 | テキスト | - | `GET /users/me` の `displayName` を表示 |
| 問題スタートボタン | ボタン | - | S-05 へ遷移 |
| 問題閲覧ボタン | ボタン | - | S-08 へ遷移 |
| 問題作成・インポートボタン | ボタン（非活性） | - | Phase1・Phase2 は disabled 状態で表示（要件定義書 F-02）。押下不可、ツールチップ等で「Phase3で提供予定」を案内してもよい |
| ログアウトボタン | ボタン | - | Cognito サインアウト、トークン破棄 |

## 4. 操作・イベント

| No | 操作 | 処理内容 | 遷移先 |
|---|---|---|---|
| 1 | 画面表示時 | `GET /users/me` を呼び出しユーザー名を取得・表示 | - |
| 2 | 「問題スタート」押下 | - | S-05 出題設定画面 |
| 3 | 「問題閲覧」押下 | - | S-08 問題閲覧画面 |
| 4 | 「問題作成・インポート」押下 | Phase1・Phase2 は非活性のため無反応（クリックイベント自体を無効化） | - |
| 5 | 「ログアウト」押下 | Cognito GlobalSignOut、クライアント保持のトークンを破棄 | S-01 ログイン画面 |

## 5. 使用API

| API | 用途 |
|---|---|
| `GET /users/me` | ログインユーザー情報（表示名等）の取得 |

## 6. エラーハンドリング

| ケース | 表示内容 |
|---|---|
| `GET /users/me` 失敗（401） | S-01 へ強制遷移し、再ログインを促す |
| `GET /users/me` 失敗（5xx/通信エラー） | ユーザー名部分を「ゲストさん」等のフォールバック表示にし、トースト通知でエラーを案内。ナビゲーションボタンは操作可能のままとする |

## 7. 備考

- Phase 3 で S-04 が活性化される際も、本画面側の変更はボタンの `disabled` 解除のみで完結するよう設計する。
