# S-05 出題設定画面

| 項目 | 内容 |
|---|---|
| 画面ID | S-05 |
| 画面名 | 出題設定画面 |
| Phase | Phase 1 |
| 認証要否 | 必要 |
| 関連機能ID | F-03 |

## 1. 概要

出題する資格種別・出題数・制限時間を設定し、出題を開始する画面。

## 2. 画面イメージ（要件定義書 §4.3 より）

```
┌─────────────────────────┐
│  ＜ 出題設定             │
├─────────────────────────┤
│  資格種別               │
│  [▼ Bronze (1Z0-085)] │
│                         │
│  出題数                 │
│  [  20  問] （空白=全問）│
│                         │
│  制限時間               │
│  [  30  分] （空白=無制限│
│                         │
│  ┌─────────────────┐    │
│  │    出題開始      │    │
│  └─────────────────┘    │
└─────────────────────────┘
```

## 3. 表示項目

| 項目名 | 種別 | 必須 | デフォルト値 | 説明 |
|---|---|---|---|---|
| 資格種別 | プルダウン | 必須 | 先頭要素（または前回選択値） | `GET /qualifications` より動的取得。`isActive=true` のもののみ表示 |
| 出題数 | 数値入力 | 任意 | 20 | 1〜100。空欄時は「全問」を意味する |
| 制限時間 | 数値入力（分） | 任意 | 空欄（無制限） | 未設定可。設定時は1分以上の整数 |
| 出題開始ボタン | ボタン | - | - | 押下でセッション作成・出題リスト取得を行い S-06 へ遷移 |

## 4. 操作・イベント

| No | 操作 | 処理内容 | 遷移先 |
|---|---|---|---|
| 1 | 画面表示時 | `GET /qualifications` を呼び出しプルダウンを構築 | - |
| 2 | 「出題開始」押下 | 入力チェック → `POST /questions/random` でランダム出題リスト取得 → `POST /sessions` でセッション作成（`totalQuestions`, `timeLimitMin`, `qualificationId` を送信） → 取得結果をクライアント状態（またはセッション情報）として保持 | S-06 出題画面（1問目を表示） |

## 5. 入力チェック仕様

| 項目 | チェック内容 | エラーメッセージ例 |
|---|---|---|
| 資格種別 | 必須選択 | 「資格種別を選択してください」 |
| 出題数 | 空欄可、入力時は整数かつ 1〜100 | 「出題数は1〜100の範囲で入力してください」 |
| 制限時間 | 空欄可、入力時は整数かつ 1以上 | 「制限時間は1分以上で入力してください」 |
| 出題数と実際の問題データ件数 | 選択資格の有効問題数が指定出題数未満の場合は、存在する問題数までを出題（要件定義書に準じ、上限に丸める） | 「対象の問題が◯問しかないため、◯問で出題します」（警告表示、処理は継続。※1） |

※1 この警告は本画面に留めない。処理を継続する仕様上、警告を出した直後に S-06 へ遷移してしまい本画面では視認できないため、[S-06 出題画面](S-06_出題画面.md) へ持ち越して表示する。

なお本画面のフォームはブラウザ標準の入力検証を無効化する（`noValidate`）。有効のままだと、出題数の `max` 属性などによる標準検証が送信を先に止めてしまい、上表のメッセージが一切表示されない。

## 6. 使用API

| API | 用途 |
|---|---|
| `GET /qualifications` | 資格プルダウンの取得 |
| `POST /questions/random` | 出題数・資格条件に基づくランダム出題リストの生成 |
| `POST /sessions` | 試験セッションの開始（`status=in_progress`） |

## 7. エラーハンドリング

| ケース | 表示内容 |
|---|---|
| 対象資格の問題データが0件 | 「出題可能な問題がありません」を表示し、出題開始不可 |
| `POST /questions/random` / `POST /sessions` 失敗 | 「出題の準備に失敗しました。再度お試しください」トースト表示、画面はS-05のまま |

## 8. 備考

- Phase 2 で追加予定の「試験モード」（試験時間と模擬試験問題セット）は本画面に切替タブ等で追加される想定だが、Phase 1 では実装しない。
- 「もう一度挑戦」（S-09からの遷移）の場合、本画面の初期値は直前の設定値を引き継ぐ。
