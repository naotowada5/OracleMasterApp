# S-08 問題閲覧画面

| 項目 | 内容 |
|---|---|
| 画面ID | S-08 |
| 画面名 | 問題閲覧画面 |
| Phase | Phase 1 |
| 認証要否 | 必要 |
| 関連機能ID | F-07 |

## 1. 概要

資格種別・大問カテゴリでフィルタリングした問題の一覧を表示し、一覧から選択した問題の詳細（問題文・全選択肢・正解・解説）を確認できる画面。出題（採点）とは異なり、正解・解説を最初から閲覧できる学習用の参照画面。

## 2. 画面イメージ

```
┌─────────────────────────┐
│  ＜ 問題閲覧              │
├─────────────────────────┤
│  資格種別 [▼ Silver SQL]│
│  大問     [▼ すべて]     │
├─────────────────────────┤
│  □ Q1. 次のSQL文で...    │
│  □ Q2. NULL値の扱いは... │
│  □ Q3. トランザクションの…│
│  ...                    │
└─────────────────────────┘

  ── 問題詳細（一覧から選択後）──
┌─────────────────────────┐
│  ＜ 一覧に戻る            │
├─────────────────────────┤
│  Q3. トランザクションの...│
│  A. COMMIT ...           │
│  B. ROLLBACK ...   ← 正解│
│  C. SAVEPOINT ...        │
│                         │
│  ── 解説 ──               │
│  トランザクションは...    │
└─────────────────────────┘
```

## 3. 表示項目

### 一覧部

| 項目名 | 種別 | 説明 |
|---|---|---|
| 資格種別フィルタ | プルダウン | `GET /qualifications` より取得 |
| 大問カテゴリフィルタ | プルダウン | `GET /categories?qualificationId={id}` より取得。「すべて」選択可 |
| 問題一覧 | リスト | 問題文の先頭部分（プレビュー、例: 全角40文字程度で truncate） |
| ページネーション/無限スクロール | UI部品 | `GET /questions` のページングパラメータに対応 |

### 詳細部

| 項目名 | 種別 | 説明 |
|---|---|---|
| 問題文全文 | テキスト | |
| 選択肢一覧（正解ハイライト付き） | リスト | 全選択肢を表示し、正解をハイライト |
| 解説テキスト | テキスト | `explanation` |
| 一覧に戻るボタン | ボタン | 直前のフィルタ状態を保持したまま一覧に戻る |

## 4. 操作・イベント

| No | 操作 | 処理内容 | 遷移先 |
|---|---|---|---|
| 1 | 画面表示時 | `GET /qualifications` でフィルタ用プルダウンを構築。既定フィルタ（資格=先頭、カテゴリ=すべて）で `GET /questions` を呼び出し一覧表示 | - |
| 2 | フィルタ変更 | `GET /categories` （資格変更時）、`GET /questions`（絞り込み条件変更時）を再取得し一覧を更新 | - |
| 3 | 一覧の問題行タップ | 選択した `questionId` の詳細（選択肢・正解・解説）を表示 | 同画面（詳細表示に切替） |
| 4 | 「一覧に戻る」押下 | - | 同画面（一覧表示に復帰） |

## 5. 使用API

| API | 用途 |
|---|---|
| `GET /qualifications` | 資格フィルタ用プルダウン |
| `GET /categories?qualificationId={id}` | カテゴリフィルタ用プルダウン |
| `GET /questions` | フィルタ条件に基づく問題一覧取得（選択肢・正解・解説を含む） |

## 6. エラーハンドリング

| ケース | 表示内容 |
|---|---|
| 該当条件の問題が0件 | 「該当する問題がありません」を一覧領域に表示 |
| 一覧取得失敗 | 「問題一覧の取得に失敗しました」トースト表示、再読み込みボタンを提示 |

## 7. 備考

- 本画面は閲覧専用であり、回答・採点・セッション作成は行わない（`OR_T_EXAM_SESSION`/`OR_T_ANSWER_HISTORY` を更新しない）。
