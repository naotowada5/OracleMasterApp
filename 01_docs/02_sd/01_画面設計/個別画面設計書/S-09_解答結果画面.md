# S-09 解答結果画面

| 項目 | 内容 |
|---|---|
| 画面ID | S-09 |
| 画面名 | 解答結果画面 |
| Phase | Phase 1 |
| 認証要否 | 必要 |
| 関連機能ID | F-06 |

## 1. 概要

試験（出題セッション）終了後に、総合成績と問題別の正誤一覧を表示する画面。

## 2. 画面イメージ

```
┌─────────────────────────┐
│  結果                   │
├─────────────────────────┤
│  総問題数: 20            │
│  正解数  : 16            │
│  不正解数: 4             │
│  正答率  : 80%           │
├─────────────────────────┤
│  問題別正誤              │
│  Q1 ◯  Q2 ◯  Q3 ✕  Q4 ◯ │
│  Q5 ◯  Q6 ✕  ...         │
├─────────────────────────┤
│  ┌─────────────────┐    │
│  │  もう一度挑戦     │    │
│  └─────────────────┘    │
│  ┌─────────────────┐    │
│  │  ホームへ戻る     │    │
│  └─────────────────┘    │
└─────────────────────────┘
```

## 3. 表示項目

| 項目名 | 種別 | 説明 |
|---|---|---|
| 総問題数 | テキスト | `OR_T_EXAM_SESSION.totalQuestions` |
| 正解数 | テキスト | `OR_T_EXAM_SESSION.correctCount` |
| 不正解数 | テキスト | 総問題数 − 正解数（回答未実施分＝時間切れによる未回答も不正解扱いとして計上） |
| 正答率 | テキスト | 正解数 ÷ 総問題数 × 100（小数点以下四捨五入） |
| 問題別正誤一覧 | グリッド/リスト | `OR_T_ANSWER_HISTORY` を元に問題番号順で ◯/✕ を表示 |
| もう一度挑戦ボタン | ボタン | 同じ出題設定（資格・出題数・制限時間）を引き継ぎ、新規セッションを作成 |
| ホームへ戻るボタン | ボタン | S-03 へ遷移 |

## 4. 操作・イベント

| No | 操作 | 処理内容 | 遷移先 |
|---|---|---|---|
| 1 | 画面表示時 | `GET /sessions/{sessionId}` でセッションのサマリと回答履歴を取得し集計・表示 | - |
| 2 | 「もう一度挑戦」押下 | 直前の出題設定（資格・出題数・制限時間）を保持したまま遷移。出題内容は再度ランダム抽選される（要件定義書 F-06） | S-05 出題設定画面（設定値プリセット済み） |
| 3 | 「ホームへ戻る」押下 | - | S-03 メイン画面 |

## 5. 使用API

| API | 用途 |
|---|---|
| `GET /sessions/{sessionId}` | セッションのサマリ情報・回答履歴の取得 |

## 6. エラーハンドリング

| ケース | 表示内容 |
|---|---|
| セッション取得失敗 | 「結果の取得に失敗しました」表示、再読み込みボタンを提示 |
| セッションが `in_progress` のまま結果画面に到達（異常系） | クライアント側で `status` を確認し、`completed`/`expired` でなければ警告を表示しつつ、取得できた範囲の集計値で表示する |

## 7. 備考

- Phase 3（F-10 進捗管理・履歴保存）で過去実績の日別管理・グラフ化が追加されるが、Phase 1 では当該セッションの結果表示のみを対象とする。
