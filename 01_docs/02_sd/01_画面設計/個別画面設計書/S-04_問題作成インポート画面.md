# S-04 問題作成・インポート画面

| 項目 | 内容 |
|---|---|
| 画面ID | S-04 |
| 画面名 | 問題作成・インポート画面 |
| Phase | Phase 3（本設計は将来実装のためのインターフェース定義。Phase1・Phase2では未実装／画面遷移不可） |
| 認証要否 | 必要 |
| 関連機能ID | F-08（問題インポート）, F-09（AI問題生成） |

> **注意:** 本画面は Phase 3 スコープであり、Phase 1・Phase 2 では S-03 からの遷移自体が発生しない（ボタン非活性のため）。本ドキュメントは将来の実装に向けた設計の置き場所として記載する。Phase 1・Phase 2 の開発では実装しないこと。

## 1. 概要

JSON ファイルによる問題インポート（F-08）と、Anthropic Claude API を利用した AI 問題生成（F-09）の2機能を提供する管理者向け画面。

## 2. 画面イメージ（Phase3実装時のイメージ）

```
┌─────────────────────────┐
│  ＜ 問題作成・インポート    │
├─────────────────────────┤
│ [JSONインポート] [AI生成]  │ ← タブ切替
├─────────────────────────┤
│ (JSONインポートタブ)       │
│  ファイルを選択            │
│  [ファイル未選択]           │
│  ┌─────────────────┐    │
│  │  検証してインポート │    │
│  └─────────────────┘    │
│  結果: 成功 18件 / 失敗 2件 │
└─────────────────────────┘

┌─────────────────────────┐
│ (AI生成タブ)               │
│  資格種別 [▼ Silver SQL] │
│  大問カテゴリ [▼ SELECT文]│
│  難易度 [▼ medium]        │
│  出題数 [  5  問]          │
│  ┌─────────────────┐    │
│  │   生成する        │    │
│  └─────────────────┘    │
│  ── 生成プレビュー（編集可）│
│  [DBに保存]                │
└─────────────────────────┘
```

## 3. 表示項目

### JSONインポートタブ

| 項目名 | 種別 | 必須 | 説明 |
|---|---|---|---|
| ファイル選択 | ファイル入力 | 必須 | `.json` のみ許可。要件定義書 §7.2 のスキーマに準拠 |
| 検証してインポートボタン | ボタン | - | クライアント側で簡易スキーマ検証後、`POST /questions/import` を呼び出す |
| 結果表示領域 | テキスト | - | 成功件数・失敗件数・失敗理由一覧 |

### AI生成タブ

| 項目名 | 種別 | 必須 | 説明 |
|---|---|---|---|
| 資格種別 | プルダウン | 必須 | `GET /qualifications` より取得 |
| 大問カテゴリ | プルダウン | 任意 | `GET /categories` より取得。未選択時は新規カテゴリ名を自由入力可 |
| 難易度 | プルダウン | 必須 | `easy` / `medium` / `hard` |
| 出題数 | 数値入力 | 必須 | 1〜20問（AI生成APIの負荷を考慮した上限） |
| 生成するボタン | ボタン | - | `POST /questions/generate` を呼び出す |
| 生成プレビュー領域 | フォーム（編集可） | - | 生成された問題文・選択肢・正解・解説をその場で修正可能 |
| DBに保存ボタン | ボタン | - | 編集後の内容を Lambda 経由で DynamoDB に登録 |

## 4. 使用API（Phase3実装予定）

| API | 用途 |
|---|---|
| `GET /qualifications` | 資格プルダウン |
| `GET /categories?qualificationId={id}` | カテゴリプルダウン |
| `POST /questions/import` | JSON インポート |
| `POST /questions/generate` | AI 問題生成・DB保存 |

## 5. エラーハンドリング（Phase3実装予定）

| ケース | 表示内容 |
|---|---|
| JSON スキーマ不正 | 該当箇所（行/フィールド）を一覧表示し、インポートを中断 |
| インポート一部失敗 | 成功分は登録し、失敗した問題のみエラー内容とともに一覧表示（要件定義書 F-08） |
| AI 生成タイムアウト（10秒超過の目安、要件定義書 §8.1） | 「生成に時間がかかっています。再度お試しください」表示 |
| AI 生成 API エラー（Claude API側障害等） | 「AI生成に失敗しました」表示、再試行ボタンを提示 |

## 6. 備考

- Phase 1・Phase 2 では、本画面への遷移経路を持たせない（S-03 のボタンが非活性のため）。
- Phase 1・Phase 2 の問題データ投入は、要件定義書 §7.2 のスキーマに準拠した JSON を用いた開発者スクリプト（`14_script`）による DynamoDB 直接投入で行う。
