# S-07 解説画面

| 項目 | 内容 |
|---|---|
| 画面ID | S-07 |
| 画面名 | 解説画面 |
| Phase | Phase 1 |
| 認証要否 | 必要 |
| 関連機能ID | F-05 |

## 1. 概要

S-06 での回答直後に表示される、正誤判定と事前登録済み解説テキストを表示する画面。

## 2. 画面イメージ

```
┌─────────────────────────┐
│  問題 5 / 20             │
├─────────────────────────┤
│      ◯ 正解！            │
│                         │
│  A. SELECT * FROM ...   │← 正解ハイライト（緑）
│  B. INSERT INTO ...     │
│  C. UPDATE SET ...      │
│  D. DELETE FROM ...     │
│                         │
│  ── 解説 ──────────────  │
│  SELECT文は...（解説文） │
│                         │
│  ┌─────────────────┐    │
│  │   次の問題へ      │    │
│  └─────────────────┘    │
└─────────────────────────┘
```

## 3. 表示項目

| 項目名 | 種別 | 説明 |
|---|---|---|
| 正誤判定アイコン・ラベル | アイコン+テキスト | 正解時: ◯ 緑色「正解！」／不正解時: ✕ 赤色「不正解」 |
| 選択肢一覧（判定結果付き） | リスト | 正解の選択肢をハイライト表示。ユーザーが選んだが不正解だった選択肢は別色（例: 赤枠）で表示 |
| 解説テキスト | テキスト | `OR_M_QUESTION.explanation`（事前登録済み、Phase1/2では動的生成しない） |
| 次の問題へボタン | ボタン | 最終問題でない場合に表示 |
| 結果を見るボタン | ボタン | 最終問題の場合に表示（「次の問題へ」の代わりに表示） |

## 4. 操作・イベント

| No | 操作 | 処理内容 | 遷移先 |
|---|---|---|---|
| 1 | 画面表示時 | S-06 からの回答APIレスポンス（正誤・正解選択肢ID・解説文）を表示。追加のAPI呼び出しは行わない | - |
| 2 | 「次の問題へ」押下 | 出題リストの次の問題をS-06に渡す | S-06 出題画面（次の問題） |
| 3 | 「結果を見るボタン」押下（最終問題） | セッションを `completed` として確定する（`PUT /sessions/{sessionId}` に完了フラグを含める、または直前の回答送信時に自動確定） | S-09 解答結果画面 |

## 5. エラーハンドリング

| ケース | 表示内容 |
|---|---|
| 解説テキストが未登録（空文字） | 「解説は準備中です」を表示（データ不備によるクラッシュを防ぐ） |
| 結果確定APIの失敗 | 「結果の確定に失敗しました。再試行してください」表示、ボタン押下前の状態を維持 |

## 6. 備考

- 本画面ではAPI呼び出しを新規に行わず、S-06での回答結果（正誤・正解ID・解説文）をそのまま表示することを基本とする。これにより画面遷移時のレイテンシを抑える。
