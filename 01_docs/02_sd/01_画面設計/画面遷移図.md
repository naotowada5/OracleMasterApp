# 画面遷移図

要件定義書 §4.2 の遷移図をベースに、新規登録・ログアウト・未認証リダイレクトの経路を補って詳細化したもの。

## 全体遷移図

```mermaid
stateDiagram-v2
    [*] --> S01

    S01: S-01 ログイン画面
    S02: S-02 新規登録画面
    S03: S-03 メイン画面
    S04: S-04 問題作成・インポート画面（非活性/Phase3）
    S05: S-05 出題設定画面
    S06: S-06 出題画面
    S07: S-07 解説画面
    S08: S-08 問題閲覧画面
    S09: S-09 解答結果画面

    S01 --> S02: 新規登録リンク
    S02 --> S01: 登録完了（メール認証後）
    S01 --> S03: ログイン成功

    S03 --> S05: 問題スタートボタン
    S03 --> S08: 問題閲覧ボタン
    S03 --> S04: 問題作成・インポートボタン（Phase1/2は非活性）

    S05 --> S06: 出題開始ボタン
    S06 --> S07: 選択肢決定（単一選択は即時／複数選択は決定ボタン）
    S07 --> S06: 次の問題へ（未終了時）
    S07 --> S09: 結果を見る（最終問題 or 時間切れ）
    S06 --> S09: 制限時間切れ（強制終了）

    S09 --> S03: ホームへ戻る
    S09 --> S05: もう一度挑戦（同一設定で再遷移、出題はランダム再抽選）

    S08 --> S03: 戻る

    S03 --> S01: ログアウト
```

## 未認証時のガード遷移

```mermaid
stateDiagram-v2
    [*] --> AccessCheck
    AccessCheck: 保護対象画面（S-03〜S-09）へのアクセス
    AccessCheck --> S01: Cognitoトークン未保持/期限切れ
    AccessCheck --> Target: トークン有効
    Target: 要求された画面を表示
    S01: S-01 ログイン画面（元の遷移先はログイン後に復帰）
```

## 遷移条件の補足

| 遷移元 | 遷移先 | トリガー | 備考 |
|---|---|---|---|
| S-01 | S-03 | ログイン成功（Cognito 認証OK） | JWT（IDトークン/アクセストークン/リフレッシュトークン）をクライアントに保持 |
| S-01 | S-02 | 「新規登録」リンク押下 | |
| S-02 | S-01 | メール認証コード確認完了 | Cognito のサインアップ確認フロー |
| S-03 | S-05 | 「問題スタート」ボタン押下 | |
| S-03 | S-08 | 「問題閲覧」ボタン押下 | |
| S-03 | S-04 | 「問題作成・インポート」ボタン押下 | Phase1・Phase2 ではボタン非活性のため遷移不可 |
| S-05 | S-06 | 「出題開始」ボタン押下 | 出題設定を元に `/questions/random` を呼び出しセッション開始（`POST /sessions`） |
| S-06 | S-07 | 単一選択: 選択肢タップ／複数選択: 「決定」ボタン押下 | 回答を `PUT /sessions/{sessionId}` で記録 |
| S-07 | S-06 | 「次の問題へ」ボタン押下（未終了時） | |
| S-07 | S-09 | 「結果を見る」ボタン押下（最終問題時） | |
| S-06/S-07 | S-09 | 制限時間切れ | クライアント側タイマーで検知、セッションを `expired`/`completed` として確定 |
| S-09 | S-03 | 「ホームへ戻る」ボタン押下 | |
| S-09 | S-05 | 「もう一度挑戦」ボタン押下 | 同一の資格・出題数・制限時間設定を引き継ぐ |
| 任意画面 | S-01 | セッション切れ・ログアウト | リフレッシュトークン失効時も同様 |
